# 虚拟国家战争 · astrbot_plugin_nationwar

一款大型文字模拟国家战争插件，适用于 AstrBot v4。在群里建立一个国家，种田、科技、造兵、外交、谍报，最终征服整个世界。

> **v1.2.0 更新**：
> - 🗺️ **地图升级为真正的地形地图** —— 不再是格子表，而是不规则大陆海岸线 + Voronoi 拼接地区 + 七种地形着色与纹理 + 势力染色 + 罗盘/比例尺/经纬网/图例；`/区域地图` 升级为单地区放大地形场景（山脊/森林/沙丘/海岸/农田/高原 + 城池首都 + 资源图标 + 信息面板）。
> - 💾 **账号存档永久化** —— 插件重载 / 重启 / 更新 / 重装都**不会重置玩家数据**；原子写 + `.bak` 回滚 + 损坏隔离；修复了旧版误把存档放在「插件目录内」导致更新即丢号的根因。
> - ⏳ **30 天未使用自动清档** —— 连续 30 天没发任何指令的账号自动注销，并级联释放其地区、组织名、外交/战争/同盟关系；偶尔发一条指令即可保号。

> **v1.1.0 起：所有回复均以合成图片发送**，`/指令图` 直接在群里发送两张大型指令图 PNG，无需再打开任何 HTML 文件。

## 特性

- 🖼️ **全图片回复**：所有指令的回复都由插件现场合成精美图片后发送（随插件打包中文字体，用户机器无需安装字体）；注册类回复保留 `@` 提及。
- 📊 **两张大型指令图直接发图**：`/指令图` 一次发送
  - 图一 · 内政经济（`assets/commands_chart1.png`，183 条）
  - 图二 · 军事外交（`assets/commands_chart2.png`，67 条）
  - 同时保留 HTML 版（`commands_chart1.html` / `commands_chart2.html`）便于浏览器查看。
- 🗺️ **真正的地形世界地图 + 地区放大地形图**：`/世界地图` `/势力图` 发送带不规则大陆、地形纹理、势力染色与图例的地形大图；`/区域地图 地区名` 发送该地区放大地形场景 + 信息面板。
- 🪪 **按 QQ 号快速注册**：账号即 QQ 号，**数据按 QQ 隔离永久保存、跨群互通**（不是群间隔）。
- 💾 **存档永久化**：`StarTools` 持久化目录 + 原子写 + 旧目录迁移；插件更新不丢号。
- ⏳ **30 天自动清档**：长期不玩的国家自动回收，级联释放全部世界状态。
- ⚔️ 经济 / 建筑 / 科技 / 兵种 / 政策 / 军事 / 外交 / 谍报 / 事件 / 排行 等完整玩法，共 250 条指令。

## 快速开始

1. 安装插件（从仓库链接安装，或用本仓库的 zip）。依赖见 `requirements.txt`（`aiohttp` + `Pillow`）。
2. 在群里发送：

   ```
   /注册
   ```

   插件会回复（@你 + 图片）：

   > 已注册成功，请输入你的组织名，指令：/初始组织名 组织名（仅在没有组织名的时候使用），不组织名称也不能游玩

3. 设置你的国家名（**不设名不能游玩**）：

   ```
   /初始组织名 你的国名
   ```

4. 发展你的国家：

   ```
   /建造 农场
   /研究 农业
   /征兵 步兵 10
   /世界地图        # 查看真实地形世界地图（图片）
   /区域地图 霜寒平原
   /进攻 地区名     # 征服世界
   /指令图          # 直接发送两张指令图
   ```

## 图片化说明（v1.1.0）

- 所有文本回复经 `core/imager.py` 用 Pillow 合成为深色霓虹卡片图，`event.image_result` 发送；超长文本自动分页为多张图。
- 中文字体 `assets/fonts/NotoSansCJKsc-Regular.otf`（Noto Sans CJK SC）随插件打包；emoji 会清洗为可渲染的短标签，避免豆腐块。
- 运行时生成的图片放在持久化数据目录 `rendered/`（`StarTools.get_data_dir()` 下），不污染插件目录；按内容哈希命名自动复用。
- 若用户环境缺少 Pillow 或字体，插件自动降级为纯文本回复，不影响游玩。
- 主题配色：内政经济类（图一）= 蓝青色，军事外交类（图二）= 红色。

## 真实地形地图（v1.2.0）

`core/geomaps.py` 使用**纯 Pillow**（无需 numpy / scipy）绘制：

- **世界地图**：每块大陆由带多频噪声的不规则海岸线多边形生成；大陆内部用**Voronoi 半平面裁剪**（Sutherland–Hodgman）把地区切成无缝拼接的锐利多边形；按地形着色并撒地形符号（山峰/树林/沙丘/浪线/田块/等高线）；有主地区叠加势力色与粗描边，首都标金星、资源标点；叠加海洋渐变、经纬网、罗盘、比例尺、地形/势力图例。
- **地区地图**：单个地区放大为地形场景（层叠山脊+雪顶 / 森林 / 沙丘 / 海浪海岸 / 透视田块 / 高原等高线），中央资源图标、城池与旗帜、首都星标、按防御值生成的塔楼，右侧信息面板（地形/资源/富集/防御/开发度/归属/周边地区），罗盘与比例尺。
- 几何全部由地区 id 确定性生成，同一地区形状稳定不抖动。

## 存档永久化 & 自动清档（v1.2.0）

- **数据位置**：默认使用 AstrBot 官方持久化目录 `data/plugin_data/astrbot_plugin_nationwar/`（与插件源码目录 `data/plugins/` 互为兄弟目录，**更新/重装插件不会覆盖**）。可用 `data_dir_override` 固定到任意绝对路径。
- **为什么以前会丢号**：旧版调用 `StarTools.get_data_dir(self)` 传错了参数类型，异常后回退到插件目录内 `data_runtime/`，插件一更新整个目录被替换，账号就"被初始化"了。v1.2.0 改为传插件名字符串，并把兜底目录放到用户主目录 `~/.astrbot_nationwar_data`，彻底规避。
- **升级迁移**：启动时自动把旧 `data_runtime` 存档迁移到持久目录（不覆盖新数据），并给老档案补齐 `last_active`（按历史时间戳兜底，不误判为过期）。
- **写入健壮性**：所有存档写入为「临时文件 + `os.replace`」原子写；每份存档保留 `.bak` 回滚点；主文件损坏自动从 `.bak` 恢复，彻底损坏的文件隔离到 `_corrupt/`（**绝不静默丢弃**）。
- **30 天自动清档**：`inactive_days`（默认 30）。玩家每次发指令刷新 `last_active`；插件启动与每次后台结算都会扫描，超过 N 天未使用的账号：

  | 回收项 | 处理 |
  | --- | --- |
  | 玩家存档 | 删除（含 `.bak`） |
  | 占领地区 | `owner`/`capital_of` 清空、`dev` 归零，变回无主 |
  | 组织名 | 从 `org_index` 释放，可被新玩家使用 |
  | 外交/战争/同盟 | 清理所有涉及该 QQ 的关系条目 |

  设 `inactive_days = 0` 可关闭自动清理。`/服务器状态` 可查看上次清理时间。

## 数据隔离说明

- **不是群间隔**：玩家数据按「QQ 号」隔离，同一玩家在任何群/私聊看到的都是同一份数据。
- **发送内容仅按会话隔断**：每个人的指令回复只回给发起会话的自己，不会串台。
- **游玩数据保存在注册账号（QQ 号）位置**：每个玩家一个独立存档（`players/<QQ>.json`），全局世界状态（`state.json`）单独保存。

## 配置项

| 配置 | 说明 | 默认 |
| --- | --- | --- |
| `starting_resources` | 新玩家初始资源（资金,粮食,石油,稀有金属,科技点） | `1000,1000,200,50,50` |
| `inactive_days` | 账号自动注销天数（连续 N 天未发指令清档；0=永不） | `30` |
| `data_dir_override` | 自定义存档目录绝对路径（留空用官方持久化目录） | `""` |
| `tick_enabled` | 是否后台自动结算 | `true` |
| `tick_interval_min` | 自动结算间隔（分钟） | `30` |
| `world_name` | 世界名称 | `艾瑟拉大陆` |
| `max_regions_per_player` | 单人领地上限（0=不限） | `0` |
