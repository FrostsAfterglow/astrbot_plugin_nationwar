# 虚拟国家战争 · astrbot_plugin_nationwar

一款大型文字模拟国家战争插件，适用于 AstrBot v4。在群里建立一个国家，种田、科技、造兵、外交、谍报，最终征服整个世界。

> **v1.1.0 起：所有回复均以合成图片发送**，`/指令图` 直接在群里发送两张大型指令图 PNG，无需再打开任何 HTML 文件。

## 特性

- 🖼️ **全图片回复**：所有指令的回复都由插件现场合成精美图片后发送（随插件打包中文字体，用户机器无需安装字体）；注册类回复保留 `@` 提及。
- 📊 **两张大型指令图直接发图**：`/指令图` 一次发送
  - 图一 · 内政经济（`assets/commands_chart1.png`，183 条）
  - 图二 · 军事外交（`assets/commands_chart2.png`，67 条）
  - 同时保留 HTML 版（`commands_chart1.html` / `commands_chart2.html`）便于浏览器查看。
- 🗺️ **完整虚拟世界地图 + 区域地图**：`/世界地图` `/势力图` 发送按归属着色、含 62 地区编号的可视化大图；`/区域地图 地区名` 发送单个地区放大图。
- 🪪 **按 QQ 号快速注册**：账号即 QQ 号，**数据按 QQ 隔离保存、跨群互通**（不是群间隔）。
- 💾 **游玩数据保存在玩家注册账号（QQ 号）对应的存储位置**。
- ⚔️ 经济 / 建筑 / 科技 / 兵种 / 政策 / 军事 / 外交 / 谍报 / 事件 / 排行 等完整玩法，共 250 条指令。

## 快速开始

1. 安装插件（从仓库链接安装，或用本仓库的 zip）。依赖见 `requirements.txt`（`aiohttp` + `Pillow`）。
2. 在群里发送：

   ```
   /注册
   ```

   插件会回复（@你 + 图片）：

   > 已注册成功，请输入你的组织名，指令：/初始组织名 组织名（仅在没有组织名的时候使用），不组织名称也不能游玩

3. 设置你的国家名（**不设名不能游玩**）：

   ```
   /初始组织名 你的国名
   ```

4. 发展你的国家：

   ```
   /建造 农场
   /研究 农业
   /征兵 步兵 10
   /世界地图        # 查看世界局势（图片）
   /区域地图 霜寒平原
   /进攻 地区名     # 征服世界
   /指令图          # 直接发送两张指令图
   ```

## 入门指令

| 指令 | 说明 |
| --- | --- |
| `/注册` | 用 QQ 号快速注册 |
| `/初始组织名 国名` | 建立你的国家（仅无组织名时可用） |
| `/重命名组织 新名` | 修改国名 |
| `/帮助` | 入门指引 |
| `/规则` | 完整游戏规则 |
| `/指令图` | **直接发送两张大型指令图 PNG** |
| `/世界地图` | **完整世界地图图片** |
| `/区域地图 地区名` | **单个地区放大图** |
| `/我的信息` | 国家总览 |

## 图片化说明（v1.1.0）

- 所有文本回复经 `core/imager.py` 用 Pillow 合成为深色霓虹卡片图，`event.image_result` 发送；超长文本自动分页为多张图。
- 中文字体 `assets/fonts/NotoSansCJKsc-Regular.otf`（Noto Sans CJK SC）随插件打包；emoji 会清洗为可渲染的短标签，避免豆腐块。
- 运行时生成的图片放在持久化数据目录 `rendered/`（`StarTools.get_data_dir()` 下），不污染插件目录；按内容哈希命名自动复用。
- 若用户环境缺少 Pillow 或字体，插件自动降级为纯文本回复，不影响游玩。
- 主题配色：内政经济类（图一）= 蓝青色，军事外交类（图二）= 红色。

## 数据隔离说明

- **不是群间隔**：玩家数据按「QQ 号」隔离，同一玩家在任何群/私聊看到的都是同一份数据。
- **发送内容仅按会话隔断**：每个人的指令回复只回给发起会话的自己，不会串台。
- **游玩数据保存在注册账号（QQ 号）位置**：每个玩家一个独立存档（`data/plugin_data/astrbot_plugin_nationwar/players/<QQ>.json`），全局世界状态单独保存。

## 配置项

| 配置 | 说明 | 默认 |
| --- | --- | --- |
| `starting_resources` | 新玩家初始资源（资金,粮食,石油,稀有金属,科技点） | `1000,1000,200,50,50` |
| `tick_enabled` | 是否后台自动结算 | `true` |
| `tick_interval_min` | 自动结算间隔（分钟） | `30` |
| `world_name` | 世界名称 | `艾瑟拉大陆` |
| `max_regions_per_player` | 单人领地上限（0=不限） | `0` |
